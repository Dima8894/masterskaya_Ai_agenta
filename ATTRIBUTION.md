# Происхождение материалов

Учебные тексты адаптированы из стартового набора команды Alpes для практикума «Мастерская ai-агента». Дополнения и сборка подготовлены для этого репозитория. Публичные материалы набора распространяются по MIT, кроме явно перечисленных компонентов.

Шрифт Noto Sans Regular: Google / Noto contributors, SIL Open Font License 1.1. Не изменён; источник: https://github.com/notofonts/noto-fonts (исторический адрес googlefonts/noto-fonts перенаправляется туда). Файл tools/fonts/NotoSans-Regular.ttf, лицензия tools/fonts/OFL.txt. Шрифт встроен в домашний PDF. Его лицензия не заменяется MIT.

ReportLab используется как внешняя зависимость сборки PDF; его код не включён. Материалы Alpes Researcher, Slota, записи встреч, фотографии участников и исходная рабочая тетрадь в набор не включены. Актуальная тетрадь доступна через https://alpes-it.ru/workshop.
