# Начните с одной задачи

## 1. Подготовьте папку

Скачайте ZIP по ссылке в [README](../README.md), распакуйте целиком в отдельную папку. Не работайте внутри открытого архива. Файлы `.md` — обычный текст; заранее заполнять их не нужно. Для новой независимой задачи удобно распаковать ещё одну копию.

## 2. Выберите одно приложение

**Codex:** установите приложение по [официальной инструкции](https://learn.chatgpt.com/docs/quickstart), войдите в аккаунт и откройте распакованную папку для локальной работы. Убедитесь, что агент видит AGENTS.md и templates/.

**Claude Code:** следуйте [официальной инструкции](https://code.claude.com/docs/en/desktop-quickstart), откройте Code и выберите папку набора для локальной работы.

**ChatGPT:** используйте [маршрут через чат](CHATGPT.md). Он подходит и без доступа к локальным файлам: вы переносите материалы и сохраняете результат самостоятельно.

Названия кнопок и доступность зависят от версии, аккаунта и настроек организации. Если раздела нет, проверьте официальную инструкцию или доступ у администратора. Подготовить описание задачи можно и без запуска агента. Ссылки проверены 23.10.2026; подписка на сервис не входит в набор.

## 3. Добавьте свою задачу

Создайте внутри папки набора workspace/inputs/ и положите туда фото схемы и один разрешённый пример. Или просто опишите задачу в сообщении. Неразборчивое фото можно заменить текстом. Начать без тетради нормально.

Скопируйте [FIRST-PROMPT.txt](../FIRST-PROMPT.txt), замените скобки своими ответами и отправьте. Можно написать «пока не знаю». Не переносите в чат секреты и документы, которые нельзя использовать в выбранном сервисе.

## 4. Получите и проверьте результат

Агент кратко опишет задачу, уточнит пробелы и предложит план. Проверьте, что правила действительно ваши, затем поручите первый прогон. Откройте созданный файл и сверьте 2–3 критерия.

Готово, когда сохранены результат и запись проверки. Если не хватает данных или доступа, готова только подготовительная часть; причина должна быть записана в workspace/checks.md.

## Если что-то пошло не так

- Агент не видит файлы: проверьте выбранную папку или приложите текст по маршруту ChatGPT.
- Задача слишком большая: выберите одну заявку, один документ или один запуск.
- Нет исходных данных: возьмите [учебный пример](../examples/supply-check/README.md).
- Агент выдумал значение: укажите источник ошибки и попросите перепроверить все похожие места.
- Не создан файл: попросите выдать его содержимое и сохраните вручную. Не считайте текст «сохранено» доказательством.
