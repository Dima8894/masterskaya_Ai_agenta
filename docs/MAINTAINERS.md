# Сопровождение и выпуск

Участнику этот раздел не нужен. Рабочий проект живёт в workspace/; не публикуйте его.

## Пересборка

Python 3.10+ и ReportLab нужны только сопровождающему. Из корня репозитория:

```sh
python -m venv .venv
# Активируйте среду способом своей ОС; затем:
python -m pip install -r tools/requirements.txt
python tools/build.py
python tools/check.py
```

Сборка создаёт CHATGPT-START.txt из общих правил и шаблонов, handouts/homework.pdf и dist/alpes-agent-starter-kit.zip. Не редактируйте CHATGPT-START.txt вручную. PDF использует включённый Noto Sans и не зависит от системных шрифтов. При изменении текста PDF редактируйте tools/build.py. Текст листа короткий; после изменений проверяйте рендер и размер страницы.

ZIP собирается по явному списку tools/release-files.json. Никаких рекурсивных включений рабочей папки. Он содержит один верхний каталог; исходники сборки доступны в GitHub, но участнику не нужны. В ZIP включены лицензия шрифта и сведения о происхождении, поскольку PDF содержит встроенный шрифт.

## Перед публикацией

1. Обновите VERSION. Пересоберите пакет и выполните check.py.
2. Просмотрите PDF после рендера, проверьте ссылки и орфографию.
3. Распакуйте ZIP в чистую папку и пройдите начало по README. Проверьте состав и отсутствие личных данных; .gitignore сам по себе недостаточен.
4. Проверьте git diff и git ls-files; не добавляйте workspace/, ключи, записи встреч, частные исходники или инструкции сборщику.
5. Опубликуйте commit, тег версии и GitHub Release в Dima8894/masterskaya_Ai_agenta. Прикрепите ZIP и homework.pdf. Проверьте ссылку releases/latest/download/alpes-agent-starter-kit.zip из README.
6. Запишите реальные проверки в QA.md. Не называйте редакционную проверку тестом с новичком или запуском в каждом приложении.

GitHub автоматически предлагает архив исходников, но основной подарок участникам — отдельный ZIP из Release. Python и Git для его использования не нужны.

## Редакционные принципы

Сохраняйте короткий маршрут: задача → правила сотрудника → первый результат → проверка. Не привязывайте набор к отрасли или одному сервису. Лицензия материалов MIT; лицензии сторонних ресурсов сохраняйте отдельно. Названия кнопок и условия аккаунтов перепроверяйте по официальным ссылкам из START-HERE.md.
