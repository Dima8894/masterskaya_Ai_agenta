# Схема моей автоматизации

Статус: шаблон. Переносим ответы из рабочей тетради, затем уточняем связи. Для ненужного компонента допустимо «не требуется».

| Ячейка схемы | Простое объяснение | Мой ответ |
| --- | --- | --- |
| Trigger | Что запускает задачу | |
| Goal | Какой итог нужен после одного запуска и зачем | |
| Context | Данные, правила и примеры для этого запуска | |
| Memory | Что сохраняем между запусками | |
| LLM | Где нужна модель и какова её роль | |
| Observe | Какие данные видим, каких не хватает | |
| Reason | По какому правилу выбираем действие | |
| Skill | Какой повторяемый способ работы используем | |
| Act | Что создаём или изменяем | |
| Tools | Через какую программу и какую операцию читаем данные или создаём результат; есть ли доступ | |
| Verify | Как проверяем правильность | |
| Повтор / завершение | Когда повторяем, останавливаемся или зовём человека | |
| Result | Что и кому выдаём | |

## Первый рабочий сценарий

Короткая последовательность: вход → действия → проверка → результат. Отметить, что делает агент, а что пока остаётся человеку. Указать точный файл результата и способ повторить запуск после реализации.

## Границы первой версии

Какие источники реально доступны; что пока заменено учебными данными; какие интеграции отложены. Не считать наличие строки «инструмент» подтверждением подключения.
