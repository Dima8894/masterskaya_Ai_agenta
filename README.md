# Alpes Agent Starter Kit

### От схемы на бумаге к первому результату с ИИ

Вы собрали схему своей задачи на практикуме «Мастерская ai-агента». Этот подарок от команды Alpes поможет перенести её в работу: сохранить ваши правила, получить первый результат и проверить его вместе с ИИ. Можно начать и без тетради.

1. **[Скачайте готовый ZIP](https://github.com/Dima8894/masterskaya_Ai_agenta/releases/latest/download/alpes-agent-starter-kit.zip)** и распакуйте в отдельную папку «Моя мастерская».
2. **Выберите одно приложение:** откройте папку в Codex или Claude Code; для ChatGPT откройте [инструкцию для чата](docs/CHATGPT.md).
3. **Добавьте фото схемы, её текст или описание задачи** и отправьте [стартовый запрос](FIRST-PROMPT.txt). Агент поможет с остальным.

**[Начать по шагам →](docs/START-HERE.md)** · [Попробовать учебный пример](examples/supply-check/README.md) · [Домашний лист PDF](handouts/homework.pdf)

## Что получится

Одна задача, три коротких документа и проверенный пробный результат: например, сравнение предложений, черновик документа или список отклонений. Ваши знания о работе станут понятными правилами, которые можно использовать в следующем запуске.

| Вы выбираете | Где идёт работа | Как сохранить результат |
| --- | --- | --- |
| Codex | В выбранной локальной папке | Агент записывает файлы при доступе к папке |
| Claude Code | В выбранной локальной папке | Агент записывает файлы при доступе к папке |
| ChatGPT | В чате с приложенными материалами | Скачайте файлы или сохраните выданный текст |

Устанавливать все приложения не нужно. Набор бесплатный; доступ к сервисам и их подписки в подарок не входят. GitHub-аккаунт, Git, Python, сервер и программирование участнику не нужны.

## Что внутри

- `AGENTS.md` — общие правила помощника; `CLAUDE.md` подключает их для Claude Code.
- `templates/` — три чистых шаблона: задача, схема, проверка.
- `workspace/` — ваша личная работа; создаётся при первом запуске и исключена из Git.
- `examples/` — разобранный пример на вымышленных данных.
- `docs/` — запуск, продолжение, помощь и руководство сопровождающему.

Папку `workspace/` не публикуйте. Первый запуск делайте на учебных или разрешённых для выбранного сервиса данных. Локальное хранение не означает, что модель работает офлайн. Автоматическая рассылка, рабочие базы и внешние интеграции подключаются отдельным шагом.
