# Помочь набору

Предложите улучшение через issue или pull request этого репозитория. Опишите, на каком шаге участник затрудняется, что вы предлагаете и как проверить результат. Используйте только синтетические примеры. Не прикладывайте личную workspace/, ключи, реальные документы или фотографии участников.

Меняя правила, обновляйте единый AGENTS.md, затем пересобирайте CHATGPT-START.txt и выпуск по docs/MAINTAINERS.md. Проверяйте текст на человеке, который не знаком с программированием. Небольшое понятное улучшение полезнее ещё одной обязательной настройки.
