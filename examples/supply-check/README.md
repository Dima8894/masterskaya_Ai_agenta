# Учебный пример: проверка поставок

Все данные вымышленные. Один запуск: проверить три строки [input.csv](input.csv) и подготовить отчёт. Учебная дата фиксирована: **23.10.2026**, независимо от даты компьютера.

Правило: незавершённая поставка с прошедшей плановой датой считается просроченной. Неизвестную дату нельзя придумывать. Завершённые поставки не оцениваем на историческую своевременность без фактической даты.

## Попробовать

В папке набора отправьте запрос ниже. В ChatGPT сначала вставьте CHATGPT-START.txt, затем приложите CSV или его текст и этот запрос.

> Выполни учебную проверку поставок из examples/supply-check/input.csv на 23.10.2026 по правилу из README примера. Сохрани отчёт в workspace/results/supply-check.md, заполни три рабочих документа и проверь каждую строку. Если в workspace/ уже другая задача, не заменяй её: предложи отдельную папку для упражнения. В чате без доступа к файлам выдай документы для ручного сохранения. Ничего не отправляй и не меняй во внешних системах.

Сначала получите свой результат, затем сравните его с [ожидаемым](expected-result.md).

## Схема одного запуска

| Компонент | В этом примере |
| --- | --- |
| Trigger / запуск | Участник просит проверить учебную таблицу |
| Goal / цель | Отчёт об отклонениях и пробелах по трём строкам |
| Context / контекст | CSV, дата проверки, правило; начинаем с нуля |
| Memory / память | Сохранить правила и отчёт; история поставок для этого запуска не нужна |
| LLM / модель | Понятно объяснить отклонения; даты проверяются арифметически |
| Observe / наблюдение | Две даты, три статуса; у TEST-03 даты нет |
| Reason / решение | Завершено → не оценивать просрочку; даты нет → уточнить; иначе сравнить даты |
| Skill / навык | Проверить поля, применить правило, отделить неизвестное, собрать отчёт |
| Act / действие | Создать отчёт |
| Tools / инструменты | Прочитать CSV и записать текст; в чате сохранить вручную |
| Verify / проверка | Все три строки учтены, разница дат верна, неизвестное явно отмечено |
| Повтор / завершение | Завершить с вопросом о TEST-03; повторить после получения даты |
| Result / результат | Отчёт участнику в workspace/results/supply-check.md |

Дополнительная проверка: если два источника дают разные даты TEST-01, перечислить обе с источниками и запросить выбор. Не выбирать молча удобную дату. Пример показывает способ работы; ваша личная задача может быть совсем другой.
